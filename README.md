# simple-calculator

A simple calculator application developed using Python and Tkinter.

## Features

- Basic arithmetic operations
- Addition
- Subtraction
- Multiplication
- Division
- Percentage
- Backspace
- Clear
- Plus/Minus
- Scientific functions
- Calculation history
- Keyboard support
- Dark theme

## Technologies Used

- Python
- Tkinter
- Math

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder.
4. Run: python calculator.py
